# 專案備份與復原

更新：2026-10-22。

此儲存庫保存 Laya × 寶可夢實驗的程式、可公開筆記、依賴版本與結果摘要。私人主檔仍是計畫與實驗敘事的編輯來源，公開文件為單向產生的備份。

## 每次備份

```powershell
.\.venv\Scripts\python.exe scripts/backup_project.py --push
```

備份程式會：

1. 確認目前為 `main` 且遠端為 `KevinYu969/Laya_pokemon`。
2. 讀取本機 `.local/backup-config.json` 中兩份指定筆記，產生去除個人路徑與主機識別的公開版本。
3. 檢查固定檔案白名單、檔案類型、大小與常見憑證格式，遇到問題即停止。
4. 有變更才建立提交；以一般 fast-forward push 上傳，核對遠端 commit 與本機一致。

不會自動處理分支衝突或使用 force push。備份 lock 用於避免同時提交；若上次程序意外中斷，先確認沒有備份程序，再處理殘留 lock。

排程設定於擁有者本機的對話自動化，每日 23:00（Asia/Taipei）。本機檔案備份需要電腦及桌面應用程式保持運作；實際排程狀態以應用程式設定與執行紀錄為準。GitHub Actions 僅執行驗證，無法讀取本機的新結果。

## 納入範圍

- `src/`、`scripts/`、`tests/`、CI 設定與依賴版本。
- `docs/` 中經公開檢查的計畫、研究與問題處理紀錄。
- `results/` 中整理過的實測摘要與來源雜湊。

原始 `outputs/`、ROM、存檔、權重、影片、快取、虛擬環境、私人設定與其他筆記不在此備份範圍。這是專案程式與整理後結果的備份，不是全硬碟或原始實驗資料的完整備份。

## 復原

1. Clone 此儲存庫，依 README 建立環境。
2. 使用 `scripts/bootstrap.ps1 -Locked` 及記錄的模型 revision 重建 CPU 環境。
3. 從擁有者原本的私人儲存位置取回 ROM、存檔及原始輸出，以雜湊核對版本。
4. `docs/` 可作為計畫與紀錄的文字復原來源；若與私人主檔衝突，先比較版本。

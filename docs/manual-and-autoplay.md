# 人工遊玩、掛機接手與速度分析

更新：2026-10-23。

## 目前可用的人工入口

人工模式不載入Laya、不呼叫Strata，不使用GPT分類。程式預設正常遊戲速度，每10秒保存checkpoint，關窗或Ctrl+C保存final.state；不覆寫來源存檔，也不由程式保存cartridge RAM。這是獨立的人工遊玩視窗，尚無同一視窗即時交接功能。

從首館完成存檔開始：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/play_manual.py --state outputs/brock-campaign-20261023-d/game-21/final.state
```

終端會列出本次`outputs/manual/<時間>/`目錄，後續AI應從該目錄的`final.state`接續；不要又選舊首館存檔而遺失人工進度。先停止原AI流程，再開人工模式；兩個獨立程序的遊戲進度不會自動合併。自動模式原有60秒限制未變更；人工入口由玩家關窗結束。

| 遊戲／模擬器功能 | 實體鍵盤 |
|---|---|
| 上／下／左／右 | 方向鍵 ↑ ↓ ← → |
| A（確認、互動） | A |
| B（取消） | S |
| Start | Enter |
| Select | Backspace |
| 暫停／恢復 | P |
| 按住快轉 | Space 空白鍵 |
| 全螢幕切換 | F11 |
| 結束並由本入口保存 | Esc 或關閉視窗 |

鍵盤需聚焦PyBoy原生視窗，`replay.html`不是人工控制介面。本機安裝的PyBoy 2.8.1 SDL2鍵盤表已核對；人工入口的來源保護／關窗保存以合成模擬器測試，尚未在本輪由真人實按驗收。

參考：[PyBoy官方鍵盤實作](https://github.com/Baekalfen/PyBoy/blob/master/pyboy/plugins/window_sdl2.py)。

## 速度瓶頸：先處理常駐與呼叫頻率

依[既有日誌分析收據](../results/performance-analysis-20261023.json)，d段22輪中：

| 指標 | 中位數 | 解讀 |
|---|---:|---|
| Laya未快取分類 | 1.378秒 | 每次需要新判斷的按鍵都付出此成本 |
| 快取命中的完整動作迴圈 | 0.105秒 | 含模擬、影像、日誌、checkpoint，非純推論時間 |
| 每輪完成動作迴圈外差額 | 18.570秒 | 混合模型載入、初始化、未完成推論、收尾；不能全歸為載入 |
| 相鄰分段轉場間隔代理值 | 2.576秒 | 混合程序、存檔觀測及Strata；未獨立量純API延遲 |

因此尚無證據說Strata是主要瓶頸。工程優先序：

1. 模型常駐、沿用分類快取；保留60秒逾時／保存檢查，不再為分段反覆重載權重。此項尚未實作，現有AI入口仍每輪啟停。
2. Strata改為事件觸發：目標改變、卡關、學招、隊伍調整時才詢問；普通走路／固定刷怪不重做高階規劃。現有仍每輪選階段。
3. 可選擇降低截圖、錄影及checkpoint頻率，保留關鍵事件與正常停止保存；先量各項時間再取捨，這輪未改現有實驗設定。
4. 真正需要新分類的Laya可另測GPU／其他私人機器的推論；也可評估以明示規則執行已驗證的固定刷怪流程，不能把規則執行宣稱新增Laya推論。

## Strata能否放其他機器？

可以。PyBoy保留本機視窗，Strata透過已支援的API遠端選階段；另一台私人設備提供可達端點、實際模型ID與認證即可接入。只傳必要的結構化遊戲摘要，不需搬ROM、存檔或私人筆記。尚未指定或測試新主機，不能承諾加速倍數。

Strata速度也受GPU顯存、記憶體頻寬、CPU與PCIe影響。先用同樣的遊戲摘要比較端到端延遲、首字延遲、有效JSON率及策略品質；大模型不一定最適合這種短JSON階段判斷。現有請求已使用reasoning_effort=none及短理由，不必為這個任務開長思考。

依據：[Strata官方API](https://github.com/Niko1221/Strata/blob/main/docs/DETAILS.md#api)、[效能與硬體說明](https://github.com/Niko1221/Strata/blob/main/docs/DETAILS.md#speed-measured)。

## 後續的人工／掛機工具設計（尚未完成）

建議同一個PyBoy程序提供人工、掛機、暫停三個模式。人工接手時先取消／隔離在途模型回覆、釋放AI按住的按鍵、保存接手點，再讓實體鍵盤獨占；交回AI時讀玩家最新進度，重新核對目標。畫面需清楚顯示目前控制者。

掛機任務應能指定區域、目標等級、捕捉名單、補血條件與停止條件。例如限定22號道路刷怪，HP低回中心、隊伍達標或遇到未知選單就暫停。這是可做成的輔助工具，但目前沒有一鍵切換熱鍵、設定面板、持續常駐或任意地圖刷怪功能。

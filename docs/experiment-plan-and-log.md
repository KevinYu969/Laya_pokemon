## 7. 問題、原因與解決紀錄

### ENV-001：PATH 的 Python 指向 Hermes 環境

- 發現時間：2026-10-22T19:19:13+08:00；階段：唯讀前置檢查。
- 分類：前置檢查發現的環境指向問題；尚未發生安裝失敗或套件污染。
- 現象：`Get-Command python` 讀回 `<USER_HOME>\AppData\Local\hermes\hermes-agent\venv\Scripts\python.exe`。
- 影響：若直接使用這個 `python -m pip install`，套件會安裝進 Hermes 的既有環境。
- 已確認原因：目前 PATH 的命令解析優先命中 Hermes 的 Python。
- 處理方案：選用獨立的 CPython 3.11.15 絕對路徑建立本專案 `.venv`，之後固定使用專案解譯器。
- 已執行驗證：`py -0p` 列出解譯器；直接執行選定解譯器讀取 `sys.version` 與 `sys.executable`，回傳 3.11.15 及預期路徑。
- 尚待驗證：專案 `.venv` 路徑、套件安裝位置、相依檢查與 Laya 載入。
- 目前狀態：解譯器選擇已核對；環境隔離方案待部署驗證。
- 文章可用重點：部署前先確認 `python` 指向哪個環境，讓讀者看到環境隔離的實際原因。

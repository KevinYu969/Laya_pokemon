# 紅版戰敗教訓與恢復條件

## 決策必讀規則

1. 單隻倒下不等於整場敗北；仍有健康隊員時，只能正常換人，不可重讀存檔洗掉結果。
2. 戰鬥期間全隊 HP 為零、畫面顯示 BLACKED OUT，或唯讀旗標進入 lost_transition，立即存證並暫停。敗北鎖不能靠更新路線解除。
3. 恢復前必須寫下原因、證據、策略調整、驗證結果。原因不明時保留疑點，不捏造模型的思考。
4. 主力 HP 不足三分之二、異常狀態或攻擊招式 PP 不足時，先走已驗證的補血路線；補血路線不支援時停下檢討。
5. 三級備用隊員不能當成十七級主力的可靠替補。遇到需要多人接戰的路線，先規畫可驗證的練等／換人流程，不能假設隊伍會共享經驗。
   依 Kevin 新要求，必須輪流將低等隊員換到首位並實際取得經驗，首輪全員至少12級，再縮小等級差；不再只練主力。
6. 戰敗後保留金錢減少、回城與事件進度，依遊戲正常恢復；未驗證改進有效前，只能稱為「已修正／待實戰驗證」。

## 累積方式

每次敗北產生本機 `battle-losses.jsonl`、原始畫面、存檔 SHA 與檢討模板。完成檢討後將可公開的教訓補進本檔；Strata 每次高階策略請求會讀取本檔前段的規則與內容雜湊。這是證據與策略規則的累積，不是重新訓練模型權重，也不保證勝率會單調提高。

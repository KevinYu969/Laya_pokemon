# 紅／藍版通關隊伍與捕捉策略

更新：2026-10-23。Kevin要求以強隊為目標，持續捕捉、培養，並依攻略選擇升級招式。

## 目標與限制

以目前紅版、妙蛙種子開局、首次聯盟冠軍／名人堂為範圍；暫以不連線交換、不用漏洞、不改記憶體，允許正常取得的傳說寶可夢規劃。這些限制下的通關效率、培育時間、招式機分配與屬性涵蓋都要考量，沒有經本專案驗證的唯一「最強六隻」。隊伍隨實際進度調整。

## 階段隊伍

| 成員 | 用途與取得時機 | 招式方向 |
|---|---|---|
| 妙蛙種子→妙蛙花 | 已取得；前期岩／水館主力 | 先學寄生種子7、藤鞭13；後續飛葉快刀、催眠粉；保留實際可用攻擊招 |
| 尼多朗♂→尼多王 | 優先在22號道路捕捉，月見山後可用月之石進化 | 地震、冰凍光束、岩崩；前期先用自然可學且已取得的招式，不預支後期TM |
| 凱西→勇基拉 | 後續24／25號道路；先丟球以防瞬間移動 | 念力→幻象光→精神強念、再生、反射壁；不假設能交換成胡地 |
| 拉普拉斯 | 西爾佛公司贈送，取得較晚；視等級落差調整 | 衝浪、自然升級冰凍光束、泰山壓頂、奇異光線；不是目前已取得 |
| 卡比獸 | 寶可夢笛劇情後，先存好自然進度再正常對戰捕捉 | 泰山壓頂、瞬間失憶、睡覺、怪力；是否使用依實際戰鬥調整 |
| 閃電鳥 | 衝浪後發電廠；捕捉與培育成本另評估 | 十萬伏特、啄鑽、飛翔，第四格彈性；不假設有大師球 |

過渡目標：綠毛蟲→巴大蝶可在紅／藍版等級17學催眠粉，協助捕捉；烈雀→大嘴雀可補飛行及後續飛翔。避免把經驗平均分散給六隻尚未成形的隊員；先集中必要主力。捕捉不等於每隻都要練到相同等級。

## 招式與資源規則

- 使用第一世代資料。紅／藍版尼多王**不能學挖洞**；妙蛙種子催眠粉41、妙蛙花55，不能混用重製版學招表。
- 稀有TM預留：TM24十萬伏特→閃電鳥；TM26地震、TM13冰凍光束、TM48岩崩→尼多王。拉普拉斯自然學冰凍光束、勇基拉自然學精神強念，減少爭用；未實作自動消耗TM。
- HM可重複使用，但第一世代不能像普通招式一樣遺忘。程式保護居合斬、飛翔、衝浪、怪力、閃光；工具招與終局四招仍需整體分配。
- 有空格先接收合法升級招式。四招已滿時提出替換計畫：例如妙蛙種子13學藤鞭，優先替換叫聲，保留寄生種子與可用攻擊招。不刪唯一攻擊招，不自動確認未知招式／忘招介面。
- 戰鬥招式以剩餘PP、威力、命中、屬性一致加成與第一世代相剋表作啟發式。尚未完整計算能力值、速度、會心、狀態、固定傷害、交換與敵方AI；不把評分稱為最佳傷害模擬器。
- 四招學習介面尚待真實畫面校準；遇到時**保存狀態並產生strategy-review.json停止**，不讓一般A對話流程盲目遺忘。規劃函式與執行介面的完成程度分開呈現。

## 捕捉循環

1. 先治療、確認圖鑑與背包；常磐商店買8顆精靈球，每次確認單顆，起始3000元可留下1400元。常磐商店不賣傷藥，不誤用重製版商品表。
2. 優先22號道路東側尼多朗♂。避開可選勁敵觸發格(29,4)/(29,5)，只在東側x≥30、y≥6探索草地。
3. 對未擁有的目標進化家族、已確認野生戰、背包有球且隊伍未滿時才提出捕捉子目標。高基礎捕捉率目標或凱西先直接投球，降低低等級目標被撞擊擊倒的風險；不保證投球成功。
4. 稀有目標的削血／異常狀態與滿隊PC操作尚待校準；遇到時停止檢查，不直接放生或覆寫隊員。現階段只讀隊伍，不能假裝已掌握PC全部持有名單。
5. 首隻尼多朗♂加入後先停在捕捉里程碑；後續擴充森林、凱西與中後期路線。**這不是已能無人值守巡遍全地圖的持續捕捉器。**

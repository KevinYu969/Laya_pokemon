# 讀者版公開檢查（2026-10-28）

檢查者：Codex；目的為整理可下載的實驗入口。這是程式與公開資料的檢查紀錄，不是零風險保證或正式滲透測試。

## 公開資料

- 檢查初始公開歷史 42 個 commits、957 個唯一 Git blobs，包含目前樹與過去版本。以常見 GitHub/Hugging Face/API token、私鑰、憑證賦值、私人端點、使用者完整路徑、email 格式掃描，再檢視命中。
- 沒有發現符合掃描規則的實際 API key、私鑰、私人服務端點或 email。測試內一筆 secret 字串為刻意的合成資料；歷史的一筆驗證結果曾含本機使用者路徑，現行檔案已相對化。沒有重寫公開歷史，舊路徑仍可能在歷史版本中找到。
- ROM、存檔、模型、影片、原始 outputs、`.local`、`.env*` 與快取由 Git ignore 排除，並由公開檔案白名單再次檢查。下載包不含作者的實際端點、登入設定或模型權重。
- 新讀者功能不讀取作者的私人筆記或設定。公開筆記以現有已整理的 docs 為限。

## 執行邊界

- 原本 `PlannerConfig` 的私人網路限制保持不變。讀者入口另外使用獨立設定，只有明確選 cloud 並在每次 probe/play 加 `--allow-cloud` 才能呼叫雲端。
- API key 只由指定環境變數讀取；設定檔拒絕多餘欄位、URL 內憑證與 query。雲端要求 HTTPS。拒絕 HTTP 重新導向，不因失敗換供應商、不記原始 API response body。
- 地端模式檢查 URL 的私人地址／主機名稱範圍；服務本身是否又代理雲端由服務擁有者負責。主機名稱的檢查不是 DNS 安全掃描。
- 模型只能回覆可用階段的 JSON，不能提供任意命令或檔案路徑。子程序使用固定 argv，沒有 shell；遊戲子程序移除該 API key，Laya 使用固定 revision 與離線快取。
- 瀏覽器 viewer 綁定 `127.0.0.1`，只提供當次遊戲的影格與白名單摘要，不提供目錄、ROM 或存檔下載。不要自行轉發到公開網路。
- 限制每次 1–20 輪，預設 3 輪，每輪有原本的遊戲時間限制與儲存點。輸出目錄唯一，來源存檔不覆寫；未知狀況、使用者中斷、模型錯誤都停止。

## 驗證與限制

讀者入口測試涵蓋硬體建議、cloud 重複同意、憑證與 redirect 邊界、非法階段、開局／續接、episode 上限、不覆寫、子程序金鑰隔離；即時畫面測試涵蓋實際像素與停止／錯誤／檢討狀態。另檢查既有完整測試與公開備份白名單，實際結果放在 [驗證收據](../results/reader-release-20261028.json)。

全新 Windows Python 3.11 環境使用鎖定依賴安裝與 `pip check`，固定 Laya 權重下載、真實 ROM 短開局與存檔續接另做收據。替代模型的 JSON/API 協定用合成傳輸測試；沒有使用任何人的付費雲端 key，也沒有重跑替代模型的八道館。其他作業系統尚未實機驗收。

依賴漏洞、供應商資料保留、模型品質及新提交仍需持續檢查。本次沒有把 README 的八館實驗成果改寫成新手入口的自動通關保證。若發現真正外洩的 key，應先撤銷／輪替，再另行處理歷史，不以只刪掉現行檔案當成解決。
